# Frontend

## Overview
This is the frontend for the Web Collective Inventory Management Solution. It's built using Vite.js with React and utilizes React Query for efficient data fetching and state management.

## Technologies
- Vite.js
- React
- React Query
- TypeScript

## Getting Started

### Prerequisites
- Node.js (v14 or later)
- npm (v6 or later)

### Installation
1. Clone the repository
2. Navigate to the frontend directory:
   ```
   cd frontend
   ```
3. Install dependencies:
   ```
   npm install
   ```

### Running the Development Server
To start the development server:
```
npm run dev
```
This will start the Vite development server, usually on `http://localhost:3000`.

## Project Structure
```
src/
  components/
  hooks/
  pages/
  services/
  utils/
  App.tsx
  main.tsx
```

- `components/`: Reusable React components
- `hooks/`: Custom React hooks
- `pages/`: Top-level components representing different routes
- `services/`: API interaction and data fetching logic
- `utils/`: Utility functions and helpers
